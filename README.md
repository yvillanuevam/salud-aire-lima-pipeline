# Salud-Aire Lima — pipeline de datos con Apache Airflow

Proyecto Final Integrador (PEDE/9 Apache Airflow): cruza la calidad del aire
(PM2.5, API OpenAQ) con las atenciones respiratorias que envian las clinicas por
SFTP, por distrito de Lima y por dia. Airflow + MinIO + Snowflake + dbt (Cosmos).
